# Contributing

OmniLinkSDK is source-available but is **not an open-source community-maintained project**.

Copyright © 2026 Abdelrahman Hussein (عبدالرحمن حسين). All rights reserved.

## Code contributions

Public code contributions are not accepted unless the repository owner explicitly invites or approves
the contribution.

Unsolicited pull requests may be closed without review.

Do not use a pull request as a way to redistribute a modified version of OmniLinkSDK.

## What is welcome

You may still open concise issues for:

- reproducible bugs;
- documentation mistakes;
- compatibility problems;
- feature ideas;
- interoperability questions that do not expose secrets.

For vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of posting exploit details publicly.

## Ideas and independent implementations

The project license allows studying the publicly visible source and independently implementing similar
ideas in your own applications, subject to the restrictions in [LICENSE](LICENSE).

That does not grant permission to copy or republish the source itself.

## Authorized contributions

If the owner explicitly authorizes a contribution, the contributor must:

- have the legal right to submit all included material;
- avoid secrets, user data, generated credentials, copied proprietary code, or incompatible licensed
  material;
- pass all CI/security checks;
- preserve OmniLink security invariants;
- accept the contribution terms in LICENSE unless a separate written agreement applies.
